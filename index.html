    Questions

    What is TIMPS Swarm?

    A universal adapter and dispatcher. It connects a catalogue of 160 specialist agents to whatever coding tool you use, then splits one request into parallel sub-tasks and gathers the results. The agents are defined as MCP tools and sub-agent files, so your tool supplies the intelligence.

    Which coding tools does it work with?

    Claude Code, Codex, Cursor, opencode, Gemini CLI, Windsurf, Cline, Continue, Aider, Goose, OpenCode and more. Run timps-swarm install-mcp to register the server and write the sub-agent files for each detected tool.

    Does it need API keys?

    Where your host can spawn native sub-agents, they run on the model you are already using. For tools that only speak MCP, the server can fall back to a provider key (Gemini, Anthropic, OpenAI or Groq) or to a local Ollama model running TIMPS-Coder.

    How do I add my own agent?

    Add a Python function in src/, register it in its package's AGENTS dictionary, then regenerate the manifest with node cli/tools/generate-manifest.js. The next install-mcp writes the new sub-agent file for every connected tool.

    Works wherever you code.
